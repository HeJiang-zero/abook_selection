# Abook 机构化用户稳定性分析设计

## 目标

从交易所视角识别长期、可重复、样本可信的盈利用户，降低把偶然盈利或过度集中交易误判为 Abook 用户的风险。筛选期请求窗口为 2026-05-01 至 2026-06-30，但有效交易和撮合数据从 2026-05-15 开始；2026-07-01 至最新数据只作为样本外验证。

ClickHouse 原始 `ods_mt5_deals` 最早有更早历史，但核验发现 2026-05-15 之前的记录均为 `is_deleted=1`；有效 Deals 和 `dwd_matched_trades` 从 2026-05-15 开始。因此不把已删除流水混入收益计算，页面同时展示原始覆盖、有效分析覆盖和删除提示。

## 数据与口径

- 有效用户来自 `risk.ods_mt5_users FINAL`，`is_deleted = 0`，账户组不区分大小写包含 `test` 或 `demo` 的账户排除。
- 用户身份使用 `(platform, login)` 去重；总体有效账户使用 `uniqExact(login)`，避免同一 Login 在平台快照重复计数。
- 交易 P&L 使用 `risk.ods_mt5_deals FINAL` 的 `action IN (0, 1)`：`profit + storage + commission + fee`。
- `action IN (2, 3)` 的资金/信用流水单独保留，不参与交易收益筛选。
- 匹配成交表用于交易行为指标：交易数、成交量、成交额、持仓时间、品种数、多空方向。
- 所有金额均为 USD，时间统一 UTC。

## 指标模型

### 结果指标

- 用户净交易 P&L：用户真实交易净结果。
- 公司理论 Bbook 利润：`-用户净交易 P&L`。
- Abook 理论利润：当前假设为 0；真实 Abook 成交数据接入后替换。
- Abook 理论风险保护：候选用户进入 Abook 后，理论上避免的 Bbook 亏损。

### 稳定性指标

- 正收益月份数、月份收益率、最差月份 P&L。
- 活跃交易天数、盈利天数占比及 Wilson 95% 置信区间。
- Profit Factor、胜率、平均盈利/平均亏损、单笔期望。
- 最大回撤、收益/最大回撤比。
- Top 1 日正收益贡献率，识别“靠一天大赚”的账户。
- 日收益标准差、P&L 波动和交易频率。
- 交易量、成交额、平均/Median 持仓时间、品种数、多空交易比例。

### 样本可信度

- 交易笔数、活跃交易天数、活跃月份数。
- 数据覆盖完整度：原始 Deals 覆盖早于 5 月 15 日，但这些历史记录已删除；有效交易/撮合覆盖从 5 月 15 日开始，5 月标记为部分月份。
- 样本等级：`high`、`medium`、`low`，低样本不允许进入 Core 结论。

## 分层规则

筛选规则继续支持可调阈值，但默认分类加入稳定性和集中度约束：

- `Abook Core`：筛选期净 P&L 为正、PF 达标、交易数和活跃天数达标、正收益月份占比达标、盈利日率下置信区间不低于配置阈值、Top 1 日贡献率不超过配置阈值；只有 Core 进入可部署 Abook 候选。
- `Abook Watch`：筛选期总体盈利，但样本、月度连续性、日度置信度或集中度存在风险；只保留作观察，不自动迁移。
- `Bbook Core`：筛选期净 P&L 为负，并以对称条件判断持续亏损；只有 Core 进入可部署 Bbook 候选。
- `Bbook Watch`：总体亏损但稳定性不足，只作观察，不自动迁移。
- `Observation`：无法形成可靠方向性结论。

评分只用于排序和解释，不使用 7 月数据，也不替代硬门槛。所有候选均返回 `stability_score`、`confidence_tier`、`selection_flags`，便于人工审计。

## 样本外验证

7 月只做验证：继续盈利、开始亏损、继续亏损、转为盈利、无交易。除已有 Precision、Recall、Lift 外增加：

- 筛选方向与验证方向一致率。
- 筛选期 P&L 与验证期 P&L 的相关性。
- Abook Core 与 Watch、Observation 的验证差异。
- 验证期理论 Bbook 利润变化和理论 Abook 风险保护。
- Wilson 95% 区间和样本不足提示。

## 页面设计

页面按“结论 → 证据 → 明细”排列：

1. 顶部显示稳定 Abook 用户数、7 月样本外成功率、理论 Bbook 风险保护、数据可信度。
2. 阶段公司利润与 Abook/Book 分流概览。
3. 月度 P&L 组合图、候选组 vs 对照组验证图、稳定性分层图。
4. 用户状态迁移、风险提示和指标定义。
5. 账户表支持搜索、分组筛选、稳定性排序、分页；只显示三个月存在非零 P&L 的账户。
6. 图表统一使用 ECharts tooltip、axisPointer、单位、数据覆盖提示；账户抽屉显示月度表现、稳定性指标、集中度和交易行为。

## 失败与限制

- 不称理论 Abook 结果为真实利润；无外部对冲成交、点差、滑点、流动性成本时必须展示警示。
- 5 月数据不是完整月份，月度连续性判断只作为辅助证据，不单独构成结论。
- 样本量不足时显示风险等级，不输出确定性的“长期盈利”结论。
- 数据查询失败或字段不完整时，页面展示错误原因，不用空数据伪装成功。
